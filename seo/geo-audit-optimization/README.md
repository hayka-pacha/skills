# GEO Audit & Optimization

Claude Code skill for Generative Engine Optimization: auditing and improving how a brand or site shows up in AI answers (ChatGPT, Perplexity, Gemini, AI Overviews). Covers fan-out query analysis, source identification, language arbitrage, parasite GEO and link-budget redesign for AI-era search.

## Install

Part of the `hayka-pacha/skills` registry. Clone the registry, then symlink this skill in:

```bash
git clone git@github.com:hayka-pacha/skills.git
ln -s "$(pwd)/skills/seo/geo-audit-optimization" ~/.claude/skills/geo-audit-optimization
```

## Triggers

AI visibility, ChatGPT or Perplexity citations, LLM rankings, GEO audit, AI search optimization, brand mentions in AI answers, "how do we appear in ChatGPT".
